# Hiatus

*Take your daydream seriously. A little structure for a lot of nothing.*

A free planning tool for anyone thinking about a sabbatical: a guided interview
that ends in a one-page brief. It separates what to plan (money, dates,
re-entry) from what to leave loose.

**Use it:** https://marylynn-mlb.github.io/hiatus/

Everything stays in your browser. There is no account, no server and no
analytics. The brief can be saved as a PDF or copied as text.
